# Пушиши для Android

Игра [pet.91i.ru](https://pet.91i.ru) в одном приложении — и питомцы виджетами на главном экране телефона, каждый в
своём. Моргают, присаживаются, спят, просят есть. Погладьте пальцем — питомец станет радостнее. Пока малыш в яйце,
на экране лежит яйцо: погладьте — согреете.

## Что приложение делает

- Сама игра — это страница `pet.91i.ru`, открытая внутри приложения (WebView). Другие адреса в нём не открываются:
  ссылки наружу уходят в браузер. Страница может попросить у приложения только две вещи: открыть настройки виджетов
  и привязать виджеты к питомцам этой игры (для этого приложение один раз получает ключ игры на этом телефоне и
  подтверждает им привязку на сайте — так же, как это сделала бы кнопка «Привязать» на сайте; ключ никуда больше не уходит).
- Сайт в браузере телефона может передать питомцев в приложение одноразовым кодом (ссылка `pushishi://move/…`).

Виджеты:

- Раз в полчаса — когда система сама будит виджет — спрашивает `pet.91i.ru`, как дела у питомцев на экране.
- Передаёт туда только одно: сколько раз вы погладили питомца (или яйцо) — и кого показывает каждый виджет и каким (малышом или взрослым).
- Картинку питомца скачивает, только когда она поменялась (малыш вырос), и режет её на кадры прямо на телефоне.
- Между этими походами ничего не работает: кадры виджета переключает сама система.
- Каждый запрос виджетов записан в журнал: меню игры → «Виджеты на главном экране» → «Что приложение отправляло».

## Чего приложение не делает

- Не просит никаких разрешений, кроме интернета и «есть ли сейчас сеть» (чтобы ходить на сайт, только когда она есть):
  ни контактов, ни места, ни файлов, ни уведомлений.
- Паролей нет вовсе: вход в игру — по 6-значному коду с другого устройства, у виджетов свой ключ, который только
  показывает питомцев. На сайте его можно отключить («Сменить ключ»), или здесь — «Отвязать виджеты».
- Нет рекламы, аналитики, сторонних библиотек: только Android и стандартная библиотека Kotlin.
- Виджеты не ходят никуда, кроме `pet.91i.ru` (и бакета, где лежат картинки питомцев, — ссылку даёт сайт).
  Страница игры, как и в браузере, загружает ещё шрифт Nunito с Google Fonts.

## Как поставить

1. Скачайте `Pushishi.apk` со страницы [релизов](../../releases/latest).
2. Откройте файл на телефоне. Android спросит, можно ли ставить приложения из этого источника (браузера) — разрешите.
3. Откройте «Пушиши». Питомцы уже живут на сайте — нажмите там в меню «Играть в приложении» (или в приложении
   «У меня уже есть Пушиши» и код с сайта). Виджеты — меню игры → «Виджеты на главном экране».

## Как проверить, что файл настоящий

Каждый файл собирается здесь, на GitHub, из этого кода (вкладка Actions) и подписан ключом студии.
Отпечаток (SHA-256) сертификата подписи:

```
E3:DC:76:1C:6A:F8:D3:0B:46:19:6B:6A:BF:87:D4:2B:B3:C1:8F:EB:38:50:E9:3A:D6:B3:B5:6E:37:1E:E8:91
```

- Подпись: `apksigner verify --print-certs Pushishi.apk` — строка `certificate SHA-256 digest` должна совпасть.
  Телефон сам следит, чтобы обновления были с той же подписью.
- Что файл собран именно здесь: `gh attestation verify Pushishi.apk --repo 91iStudio/PetAndroid`.
- Контрольная сумма — в `SHA256SUMS.txt` рядом с файлом.

## Собрать самому

JDK 17, Android SDK (platform 35), Gradle 8.11: `gradle assembleRelease`. Без ключа студии получится
неподписанный APK — подпишите своим или соберите `gradle assembleDebug`.
